## Daily Automated Security Report

A daily report is generated by `scripts/daily_security_report.py` (systemd user
timer `daily-security-report.timer`, 06:30) and covers:

- **Local system** — non-loopback listeners, host firewall, sshd, pending OS
  updates, service health, Tailscale exposure, disk/load, user-journal errors.
- **Code** — per-repo secret scan of the working tree plus a value-aware scan
  of newly committed lines since the last run (`memory/security-reports/state.json`).
- **Public sites** — HTTP status, TLS certificate expiry, HSTS header.
- **Public repos** — GitHub visibility + latest push per public repo.

Reports are written to `memory/security-reports/YYYY-MM-DD.txt` (gitignored).
Email delivery via ProtonMail Bridge is opt-in: enable with
`~/.config/substrate/security_report.json` (`{"email": {"enabled": true, ...}}`).

### Posture

- Secrets are never committed: value-aware pre-commit hook + `scripts/scan_secrets.sh`.
- Public repos were scrubbed on 2026-08-08 (git-filter-repo) after an OpenClaw
  gateway credential leaked into history; all branches force-pushed.
- Services bind loopback-only; the ops panel is exposed tailnet-wide via
  `tailscale serve :10000` and is protected by tailnet ACLs (not a shared secret).
