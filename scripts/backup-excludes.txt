# restic --exclude-file for scripts/backup_snapshot.sh
#
# Version-controlled exclusion list so backup scope is reviewable in git rather
# than buried in shell flags. Patterns follow restic's exclude syntax:
# https://restic.readthedocs.io/en/stable/040_backup.html#excluding-files
#
# Rule of thumb: exclude anything that is (a) regenerable from a declared
# source, or (b) large binary media that a re-download can restore. Never
# exclude declarative configuration or accumulated state that cannot be rebuilt.

# --- Generic regenerable build/VCS noise -----------------------------------

**/node_modules/**
**/__pycache__/**
**/.venv/**
**/dist/**
**/.mypy_cache/**
**/.ruff_cache/**
**/.pytest_cache/**
