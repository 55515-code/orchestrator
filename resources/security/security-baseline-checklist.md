# Small Business Security Baseline Checklist

**Version:** 1.0 · **Category:** Security · **License:** Free

The 80/20 of small-business security. If you do nothing else this quarter,
do these fifteen items.

## Accounts and Access

- [ ] Enforce multi-factor authentication (MFA) on email, cloud admin, and VPN
      — no exceptions, including the owner
- [ ] Use unique passwords everywhere; adopt a password manager
- [ ] Remove access for ex-employees the same day they leave
- [ ] Audit shared mailboxes and shared logins; eliminate them where possible

## Devices and Endpoints

- [ ] Encrypt every laptop and phone (BitLocker/FileVault/OS encryption)
- [ ] Enable automatic updates on OS and software (browser, PDF, Office)
- [ ] Require lock screen on idle (2–5 minutes) with a passcode
- [ ] Use standard (non-admin) accounts for daily work; admin only for installs

## Email and Phishing

- [ ] Enable anti-phishing protections on your email platform (M365/AAD, GWS)
- [ ] Train staff quarterly with realistic phishing simulations
- [ ] Establish a "report it without shame" culture for suspicious mail
- [ ] Set up a documented process for wire-transfer / payment-change requests
      (always verify by a second channel)

## Data and Backups

- [ ] Back up critical data automatically, daily, offsite (cloud or rotated drive)
- [ ] Test restoring from backup at least quarterly — document the test

## Network and Monitoring

- [ ] Ensure the office Wi-Fi uses WPA2/WPA3 with a strong passphrase
- [ ] Review the router/firewall config for remote admin left exposed
- [ ] Turn on basic logging (email, cloud) and review weekly

## Documented Answers (write these down once)

- [ ] Who is the security owner/point of contact?
- [ ] What is the incident response number to call first?
- [ ] Who is the backup/insurance provider, and is the policy current?
