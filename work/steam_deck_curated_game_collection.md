# Steam Deck Curated Emulation Collection

Status: provisional candidate list pending a read-only inventory of the owner's lawful dumps.

## Collection Philosophy

Target a collection that feels chosen, not accumulated:

- Start with **100-150 total games** across all systems.
- Give GameCube and Wii the largest shelves because they match the owner's interests and run well on Steam Deck.
- Keep only one or two representatives from repetitive annual series.
- Favor action-adventure, platforming, racing, action RPGs, character action, and approachable local multiplayer.
- Keep first-person shooters and pure puzzle games out unless they are exceptional crossover picks.
- Put demanding PS3 games in an **Experimental** collection until each completes a real-device test.
- Prefer a native Steam version when it is materially easier to run, more stable, or more battery-efficient than emulating the same release.

## ES-DE Collection Layout

Keep the visible home screen to seven collections:

1. **Favorites**: 20-30 current games, rotated over time.
2. **Mario & Friends**: Mario, Luigi, Donkey Kong, Yoshi, Wario, and related sports/party games.
3. **Action & Adventure**: Zelda, God of War, Prince of Persia, Resident Evil, and similar games.
4. **Souls & Action RPGs**: Demon's Souls, Monster Hunter, Dragon's Crown, Muramasa, and selected RPGs.
5. **Racing & Sports**: Mario Kart, F-Zero, SSX, Burnout, Ridge Racer, MotorStorm, and Excite Truck.
6. **Couch Multiplayer**: a deliberately small set that works with connected controllers.
7. **Experimental**: PS3 and other titles still undergoing validation; hide this in guest mode.

System views remain available, but collections should be the normal entry point.

## Scoring Rules for the Inventory Pass

Each discovered game receives a score out of 10:

| Signal | Points |
| --- | ---: |
| Direct genre/series fit | 0-3 |
| Critical or historical quality | 0-2 |
| Steam Deck emulation quality | 0-2 |
| Distinct from games already selected | 0-1 |
| Local multiplayer or short-session value | 0-1 |
| Exclusive/best version worth emulating | 0-1 |

Default decision:

- **8-10**: main curated collection.
- **6-7**: alternate or genre collection.
- **4-5**: archive, visible only by system.
- **0-3**: hide from normal ES-DE views.

Nothing is deleted. Curation changes visibility and collections only.

## Questions That Determine the Final Cut

1. Should the final visible library target about **75**, **150**, or **250** games?
2. How important is local multiplayer: occasional, important, or a major part of the console?
3. For PS3, include only smooth games, accept minor compromises, or include ambitious games needing per-title tuning?
4. Do long JRPGs belong in the main collection, or should they be limited to the very best two or three?
5. Are horror games welcome, and if so, atmospheric horror or also graphic/action horror?
6. For motion-heavy Wii games, will real Wii Remotes be used while docked, or must every game work from Deck controls and ordinary gamepads?
