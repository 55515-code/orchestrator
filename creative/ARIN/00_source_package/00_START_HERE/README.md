# ARIN Kilo Handoff

Start with `KILO_MASTER_DIRECTIVE.md`.

This package contains the canonical poster, story canon, voice/art rules, autonomous substrate plan, novel pipeline, economic/release framework, and quality gates.

The intended result is not a one-off manuscript generator. It is a self-improving but bounded creative production system that leaves behind reusable contracts, memory, evaluation, publishing, cost-accounting, and promotion machinery.

**Human approval remains mandatory for spending, legal agreements, public publishing, and outbound promotion.**
