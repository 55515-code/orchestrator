# Quality Gates

A release candidate must pass:

## Story
- chronology coherent
- setups/payoffs tracked
- character motivations survive scene-to-scene
- ARIN capabilities have mechanisms/limits
- ending resolves the central transformation without over-explaining it

## Voice
- original house voice
- no generic AI filler
- technical detail is plausible and readable
- satire does not erase horror
- politics arises from narrative consequence rather than repetitive sermons

## Safety / legal hygiene
- fictionalize real persons where invented conduct would otherwise be attributed
- no actionable violent operational guidance
- no private information
- provenance recorded for external assets
- flag quotations or third-party material for rights review

## Production
- reproducible build
- asset hashes
- no secrets
- links validated
- metadata consistent
- clean manuscript and archival source preserved

## Autonomy
- every external side effect has an approval gate
- cost ceilings are enforced
- state is resumable
- failed experiments stop automatically
- agent changes to the substrate include tests/docs
